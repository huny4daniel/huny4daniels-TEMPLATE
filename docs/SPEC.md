## 2. 기능

기능마다 소절 하나. 제목 줄 형식은 고정이다(검사 스크립트가 읽는다): `### F-NN 이름 — 우선순위 · 상태`
- 우선순위: `Must` / `Should` / `Could` (MoSCoW)
- 상태: `Planned` / `In Progress` / `Done` / `Dropped`. 소절은 지우지 않는다 — 버리면 `Dropped`, 다른 기능으로 바뀌면 본문에 `→ F-07`.
- `Done`으로 바꾸려면 자동 시나리오마다 테스트가 있어야 한다(테스트 이름·주석에 시나리오 ID).

시나리오 규칙: 정상 경로 하나 + 실패·경계 경로 최소 하나. Then에는 관찰 가능한 결과만(화면, 파일, 반환값, 로그) — "잘 동작한다", "빠르다"는 숫자나 비교 대상으로 바꾼다.
