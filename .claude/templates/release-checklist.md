# 릴리즈 체크리스트: vX.Y.Z

## 준비
- [ ] 마일스톤의 모든 이슈 종료 또는 다음 버전으로 이동
- [ ] `main` CI 통과
- [ ] 버전 번호 결정 (SemVer: MAJOR 호환 깨짐 / MINOR 기능 추가 / PATCH 수정)
- [ ] `CHANGELOG.md` `[Unreleased]` → `[X.Y.Z] - YYYY-MM-DD`
- [ ] README·문서의 버전/스크린샷 갱신 필요 여부 확인

## 빌드 전 점검
- [ ] 클린 환경에서 설치·실행 확인
- [ ] 주요 사용자 시나리오 수동 확인
- [ ] 이전 버전에서 업데이트 시 설정·데이터 유지 확인

## 배포
- [ ] 커밋 → `git tag vX.Y.Z`
- [ ] 커밋과 태그 함께 push
- [ ] release 워크플로 성공 확인
- [ ] 배포물(설치 파일, APK 등) 다운로드해 실제 설치 확인

## 사후
- [ ] 릴리즈 노트 확인
