description: 세션 마무리 — 진행 상태와 기록을 갱신하고 커밋 제안
---

docs/PROCESS.md의 기록 규칙을 따른다.

1. 이번 세션에서 한 일을 `git diff`, `git status`, 대화 내용으로 정리한다.
2. 진행 중인 docs/plans/ 문서가 있으면 체크박스와 진행 기록(완료 / 발견한 문제 / 다음 할 일)을 갱신한다.
3. docs/STATUS.md를 갱신한다:
   - 현재 단계·마일스톤·진행 중 작업·다음 할 일·최종 갱신일
   - 사람 대기 항목 (새로 요청한 것 추가, 끝난 것 삭제)
   - 이번 세션의 결정과 가정
   - 세션 로그에 한 줄 추가 (10개 초과분은 삭제)
4. 이번 세션에서 같은 실수를 반복했거나 환경 함정을 발견했으면 AGENTS.md Gotchas에 추가한다.
5. 사용자에게 보이는 변경이 있으면 CHANGELOG `[Unreleased]`를 갱신한다.
6. 변경 요약을 보여주고 커밋한다. 작업 브랜치에 있으면 바로 커밋·push하고, `main`에 직접 커밋해야 하면(문서만 바뀐 경우, docs/process/git-flow.md) [승인 요청]한다. 다음 세션에서 이어갈 첫 행동을 한 줄로 알려준다.
